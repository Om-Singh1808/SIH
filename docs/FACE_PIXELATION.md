# Face-only live preview

YOLO11 detects people on the original BGR frame for counting and tracking.
Preview redaction separately runs OpenCV YuNet to locate faces, then mosaics
only those rectangles with a 10% margin. Clothing, bodies and shelf details stay
visible. No face recognition, identity matching or embedding is performed.

Both `senseedge.preview.PreviewStreamer` (including unannotated stills and
MJPEG) and `retailsense_edgecv.annotate.annotate_frame` use this redactor.
The existing `preview_blur_people` flags keep their API names and now enable
face-only redaction. Pixelation never modifies the frame used for analytics.

## Setup

Install the existing `packages/contracts` and `packages/edgecv` dependencies
(OpenCV 4.8 through 4.x for these pinned YuNet weights),
then run from the repository root:

```sh
python tools/fetch_models.py --faces-only
```

The regular model export command also downloads YuNet. The downloader checks
the pinned SHA-256 before replacing weights. Models remain ignored by Git;
include `models/face_detection_yunet_2023mar.onnx` in the edge model volume for
deployment. Set `RS_FACE_MODEL` to an absolute path for other installations.
Restart after replacing weights at an existing path.

If the optional CV package/model is missing or inference fails, the preview
withholds image pixels (black canvas, with optional overlays) and logs the
reason. It does not silently transmit an unredacted image. Analytics continue.

## Detection and limits

YuNet searches the full frame at a maximum dimension of 960 pixels, even when
there are no confirmed person tracks. Additional person crops at 320 pixels
provide another scale for small or large faces. Both passes preserve aspect
ratio, pad to multiples of 32 and map face boxes back to the original image.
Face pixelation uses at most eight mosaic cells on either axis.

Face-only masking depends on successful localization: profiles, occlusion,
motion blur and very small faces can still be missed. It is not a guarantee of
anonymity. Evaluate representative camera footage before relying on it for
privacy. No labeled camera dataset is included, so this change does not claim
a measured gain in precision, recall or mAP.

The ONNX YOLO decoder now requires person to be the highest-scoring class,
matching the Ultralytics single-label path; a candidate scoring 0.60 for person
and 0.95 for bicycle is no longer counted as a person. Non-finite coordinates
and non-positive dimensions are rejected before NMS.

The SenseBoard Vision Lab page is a separate prerecorded simulation. Its MP4
and scripted overlay boxes are not generated by this live inference pipeline;
this backend change cannot restore already-pixelated bodies in that footage.

## Validation

```sh
python -m pytest --import-mode=prepend packages/edgecv/tests apps/senseedge/tests/test_preview_faces.py
```

Tests cover masks leaving body/background pixels intact, original-frame
immutability, coordinate transforms, image boundaries, faces without tracks,
crop recovery, missing models, inference failure and class filtering. A real
camera accuracy evaluation should separately report person precision/recall,
face miss rate, face-box overlap and latency on a held-out labeled sample.
